## About the Internship

The Oasis Infobyte Python Programming Internship focuses on developing practical Python applications and understanding real-world software development concepts through hands-on projects.

# Projects

## Task 1: Voice Assistant

### Description

A Python-based Voice Assistant that responds to voice commands and performs useful tasks such as providing the current time and date, searching the web, and fetching information from Wikipedia.

### Features

* Speech Recognition
* Text-to-Speech Conversion
* Tell Current Time
* Tell Current Date
* Google Search
* Wikipedia Search
* Voice-Based Interaction

### Technologies Used

* Python
* SpeechRecognition
* Pyttsx3
* Wikipedia API

---

## Task 2: BMI Calculator

### Description

A graphical BMI Calculator developed using Python Tkinter that calculates Body Mass Index based on user input and displays the health category.

### Features

* BMI Calculation
* Health Category Detection
* User-Friendly Interface
* Error Handling
* Instant Result Display

### Technologies Used

* Python
* Tkinter

---

## Task 3: Random Password Generator

### Description

A GUI-based Password Generator that creates secure and random passwords based on user-defined length.

### Features

* Random Password Generation
* Strong Password Creation
* Letters Support
* Numbers Support
* Symbols Support
* Simple GUI Interface

### Technologies Used

* Python
* Tkinter
* Random Module
* String Module

# Installation

### Clone the Repository

```bash
git clone https://github.com/sujaljhala125/OIBSIP-Python-Programming.git
```

### Navigate to Project Folder

```bash
cd OIBSIP-Python-Programming
```

### Install Dependencies

For Voice Assistant:

```bash
pip install pyttsx3
pip install SpeechRecognition
pip install PyAudio
pip install wikipedia
```

# How to Run

### Voice Assistant
